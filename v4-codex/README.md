# 《远远乡》v4 界面补丁

适用于 [完整版 v4 发布包](https://github.com/chicken-person/yuanyuanxiang-galgame-assets/releases/tag/full-20261119-v4)。补丁包含界面代码与章节插图，游戏视频来自完整版。

## 这次更新

- 点「心香」或「心碑」后先看见印有奶奶或母亲插画的布面书。镜头约 2.6 秒推近到俯视，封面沿书脊打开，露出对应章节。
- 章节目录采用回忆册样式。可以点篇名跳转、拖动纸角、点击翻页按钮，或用键盘左右方向键。手机竖屏可左右滑动插画。
- 开书可跳过。开启系统「减少动态效果」时直接进入目录。从正文返回时恢复此前所在章节页。
- 补丁同时包含上一轮的标题入场动画、双线入口字号调整，以及过场期间的旧选项闪帧修正。逐镜头的 Muse 提示词见 [审片说明](Muse-shot-review.md)。

## 安装

1. 解压完整版，并找到含有 `index.html` 和 `game/` 的游戏根目录。
2. 从本分支的 **Code → Download ZIP** 下载补丁。解压后把 `v4-codex/` 里的 `index.html` 和 `game/` 复制到游戏根目录，合并同名目录并覆盖同名文件。
3. 启动游戏用的本地服务，再刷新浏览器。也可以在游戏目录运行 `python -m http.server 8334 --bind 127.0.0.1`，然后打开 [本机游戏](http://127.0.0.1:8334/)。
