# 《远远乡》v4 本地修订

基于 [完整版 v4.0 发布包](https://github.com/chicken-person/yuanyuanxiang-galgame-assets/releases/tag/full-20261119-v4)。基础包 SHA-256 为 b66668e87ac3839a9f23424b9b566d012e825fba5f149598d873b511ec195f83。

这次代码修订让封面书名在约 2.8 秒内由小到大落位。双线入口书名约放大两倍，「心香／心碑」放大 50%，并修正外层滚动导致的舞台偏移。自动细节选项在浏览器绘制前隐藏，全屏视频期间也不显示旧选项框。

代码补丁的三个文件位于 game/ 目录。已有 v4 时，把该目录下的同名文件覆盖到已解压游戏的 game/ 目录，再刷新浏览器。游戏媒体仍使用 v4 成片。逐镜头说明是下一轮 Muse 制作任务。

完整修订版解压后，在含 index.html 的目录启动本机静态服务，例如 `python -m http.server 8334 --bind 127.0.0.1`，再用浏览器打开 `http://127.0.0.1:8334/`。
